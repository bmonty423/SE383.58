Week 2 Activity reflections

Owen Pimentel


1. how version control acted as a system of record
-Version control stores and dates every change to a project. This creates a timeline of archived versions that can be accessed and viewed to see the progression of the project.

2. why meaningful commit messages mattered
-Projects can be massive in scope, with many different functions and systems that work together. If a change is made that ends up breaking something, its important to be able to identify what was changed and why it was changed, so it can be fixed quickly. without meaningful commit messages, teams could waste time combing through file after file in an attempt to locate the error.

3. how visibility reduced collaboration risk
- Visibility reduces risk by ensuring accountability. If you can see the content of edits and who made said edits, then you can find who keeps breaking things.
