- How version control acted as a system of record
Version control acts as a system of records by keeping all previous verisons of the repository saved upon pushing changes, and acts as a timeline of changes. All previous version are viewable and restorable if needed.

- Why meaningful commit messages mattered
Meaningful commit messages matter because it is important to keep a clear record of the changes being made, as well as when and why they were made. This gives more context to each change, which makes for clear communication with team members, easier troubleshooting, and improved conflict resolution.

- How visibility reduced collaboration risk
Visibility reduces collaboration risk because clear communication between team members provides clear context and intention for changes made, as well as making it easier to avoid conflicts. It also reduces confusion in the event of an issue, as all team members take responsibility for thier own work, and thier thought processes on the changes are readily available.
